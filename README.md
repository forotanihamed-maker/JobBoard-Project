# JobBoard

نسخه اولیه‌ی بخش جستجوی فرصت‌های شغلی. کاربر می‌تواند شغل‌ها را از یک API واقعی دریافت کند، بر اساس عنوان جستجو کند و جزئیات هر موقعیت را ببیند.

داده‌ها از [Arbeitnow Job Board API](https://www.arbeitnow.com) گرفته می‌شوند.

## امکانات

- دریافت شغل‌ها از API (بدون داده‌ی ثابت داخل پروژه)
- نمایش نتایج به‌صورت کارت: عنوان، شرکت، محل، نوع همکاری، Remote/On-site، خلاصه‌ی توضیحات و دکمه‌ی `View Details`
- جستجو بر اساس عنوان شغل
- جزئیات کامل شغل در یک Modal (بستن با Escape، کلیک روی پس‌زمینه یا دکمه‌ی بستن)
- وضعیت‌های مختلف: Loading، Success، Empty و Error
- طراحی Responsive (موبایل، تبلت و دسکتاپ) و پشتیبانی از Dark Mode

## جستجو چگونه کار می‌کند؟

- **Debounce**: برای هر حرف درخواست ارسال نمی‌شود؛ بعد از ۴۰۰ میلی‌ثانیه توقف تایپ، جستجو انجام می‌شود.
- **لغو درخواست قبلی**: با `AbortController`، اگر کاربر عبارت را عوض کند، درخواست قبلی لغو می‌شود تا نتیجه‌ی قدیمی روی نتیجه‌ی جدید اثر نگذارد.
- **فیلتر روی عنوان**: همه‌ی کلمات باید در عنوان باشند، به هر ترتیب و بدون حساسیت به حروف بزرگ و کوچک (مثلاً `developer react` هم `React Developer` و هم `Developer (React)` را پیدا می‌کند).
- **جستجوی خالی**: ۱۰۰ شغل اول نمایش داده می‌شود.
- **خطای HTTP**: پاسخ‌های ناموفق (مثل 404 یا 500) به‌عنوان خطا مدیریت و به کاربر نمایش داده می‌شوند.

## محدودیت‌ها

- فقط صفحه‌ی اول API (حدود ۳۰۰ شغل) دریافت می‌شود و حداکثر ۱۰۰ نتیجه نمایش داده می‌شود.
- API پارامتر `search` را فیلتر نمی‌کند (با یک کلمه‌ی بی‌معنی هم لیست عادی برمی‌گرداند)، بنابراین فیلتر واقعی در سمت کلاینت انجام می‌شود.

## تکنولوژی‌ها

React، JavaScript، HTML، CSS، Fetch API و Hooks. در این پروژه از Backend اختصاصی، Database، Redux، Axios، Tailwind، Bootstrap و jQuery استفاده نشده است.

## اجرای پروژه

نیازمند Node.js نسخه ۲۰ یا بالاتر.

```bash
npm install
npm run dev
```

دستورهای دیگر:

```bash
npm run build     # ساخت نسخه‌ی نهایی
npm run preview   # مشاهده‌ی نسخه‌ی ساخته‌شده
npm run lint      # بررسی کد
```

## ساختار پروژه

```
src/
  components/
    Header.jsx            هدر و باکس جستجو
    SearchBox.jsx         input کنترل‌شده‌ی جستجو
    Jobs.jsx              دریافت داده، فیلتر و نمایش وضعیت‌ها
    JobCard.jsx           کارت هر شغل
    JobDetailsModal.jsx   جزئیات شغل
  hooks/
    useFetch.jsx          درخواست، وضعیت‌ها و لغو درخواست
    useDebounce.js        تأخیر در اعمال مقدار جستجو
  utils/
    filterJobs.js         فیلتر خالص بر اساس عنوان
  App.jsx                 نگهداری state متن جستجو
  Style.css
```

`searchTerm` در `App` (نزدیک‌ترین والد مشترک) نگهداری می‌شود؛ `SearchBox` آن را تغییر می‌دهد و `Jobs` فقط آن را می‌خواند.
